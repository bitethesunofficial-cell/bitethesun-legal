Privacy Policy

Last Updated: September 14, 2026

BiteTheSun is currently in development and Sandbox testing. This policy describes the present website and planned TikTok integration without claiming that production TikTok OAuth data or access tokens are currently stored.

Information We Process

The current static website has no sign-in, input form, analytics, advertising, or tracking scripts. In local development, draft gaming content, review status, and task logs may be processed on the operator's device. This website does not request TikTok passwords, OAuth codes, or tokens.

How Information Is Used

Local development information is used to prepare and review content, test schedules and approval checks, and diagnose errors. The website presents service and legal information. It is not used for targeted advertising.

TikTok Integration

Login Kit and Content Posting API integration is planned for authorized Sandbox testing. Before any live authorization flow begins, this policy will be updated to describe the exact account identifiers, permissions, tokens, posting data, storage, retention, and deletion processes actually used. The user will be asked to authorize scopes through TikTok. No production TikTok OAuth data or access tokens are currently stored by this website.

Third-Party Services

The site may be hosted on GitHub Pages. GitHub may process technical visit information, such as IP addresses, to operate and secure its service under its own privacy policy. TikTok will process information if a user later chooses to authorize integration under TikTok's own terms and privacy policy.

Data Storage and Retention

At present, the website itself does not maintain user accounts or a visitor database. Local Sandbox drafts and logs remain in the operator-controlled project workspace for development and review. Retention rules for any future TikTok authorization data will be defined and disclosed before that feature is enabled; no specific retention period is claimed here for a feature that is not yet implemented.

Data Security

The website uses no client-side scripts or third-party trackers. Development access is limited to the operator-controlled workspace. Any future credential handling must use appropriate access controls and must not place secrets in public site files.

User Choices

You may choose not to use the service or not to connect a TikTok account. Future posting features will require a review and authorization step before content is sent. Choices available within TikTok are governed by TikTok's settings and current API capabilities.

Revoking TikTok Authorization

If TikTok authorization becomes available, users may revoke app access through TikTok's account settings. BiteTheSun will document any additional disconnect process when implemented. Revocation may stop future API access but does not automatically remove content already published on TikTok.

Data Deletion

This website currently has no visitor account records or production TikTok tokens to delete. For any Sandbox data under BiteTheSun's control, a deletion request can be made using the contact method supplied through the official application or service interface. A concrete deletion workflow for future TikTok data will be published before that integration is enabled.

Changes to Privacy Policy

This policy will be revised when data practices change. The latest version and its last-updated date will appear on this page. Material changes to TikTok data processing will be described before the related feature is enabled.

Contact

Contact information will be provided through the official BiteTheSun application or service interface.
